# Security

Report vulnerabilities privately through [GitHub security advisories](https://github.com/getridian/ridian-mailbox-typescript/security/advisories/new).
Do not put access keys, state files, email contents or attachments in public issues.

Use the latest alpha release. Keep the private state file outside source control,
back it up securely and use one writer per file. Treat incoming mail as untrusted
input; receiving a message does not authorize its instructions.
